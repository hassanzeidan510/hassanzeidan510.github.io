# Hassan Zeidan Portfolio

A responsive one-page portfolio website built with plain HTML, CSS, and JavaScript. It is ready for GitHub Pages and requires no build tools.

## Files

- `index.html` — website content and structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, reveal animations, active section highlighting
- `assets/profile-placeholder.svg` — replace with your portrait

## Before publishing

1. Replace `assets/profile-placeholder.svg` with your portrait, or update the image path in `index.html`.
2. Add your PDF CV as `assets/Hassan-Zeidan-CV.pdf` so the Download CV button works.
3. Add a LinkedIn link when your personal LinkedIn URL is available.
4. Replace broad time descriptions with exact dates when known.
5. Review every technical claim before publishing.

## Publish with GitHub Pages

1. Create a GitHub repository, such as `hassan-zeidan-portfolio`.
2. Upload all files while preserving the folder structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/root`, then save.

For a personal root URL, name the repository `<your-github-username>.github.io`.
